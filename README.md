# C 盘扩容助手

把 D 盘的空闲空间划一部分给 C 盘 —— 一份说明 + 一个诊断脚本，动手前先看清自己机器的分区布局，避免踩坑。

> 不造轮子：真正执行分区搬迁的是现成工具（傲梅分区助手 / DiskGenius 免费版），本仓库负责**诊断、算量、给步骤**。

## 为什么 Windows 自带工具不行

「磁盘管理」的「压缩卷」只能把空间从分区**尾部**切出来。D 盘在 C 盘右边时，切出来的空闲空间落在 D 的右边，和 C 之间隔着一整个 D，于是 C 的「扩展卷」始终是灰的。想用自带工具扩 C，只有一条路：删掉整个 D —— 数据全没。

所以实际做法是：用分区软件把 D 的数据整体往后挪，让空闲空间贴到 C 的右边界，再扩 C。

## 三步走

### 1. 先跑诊断

```cmd
右键「开始」→ Windows PowerShell → 粘贴：
powershell -NoProfile -ExecutionPolicy Bypass -File scripts\check-partitions.ps1 -TakeGB 10
```

脚本会列出物理磁盘、分区顺序、C 右边紧邻的是什么（空闲 / D / 恢复分区）、D 能压缩出多少，并给出结论。**不写盘、不修改任何分区**，纯读取。

### 2. 按结论选路径

| 诊断结论 | 怎么做 |
|---|---|
| C 右边紧邻空闲空间 | 自带磁盘管理：右键 C → 扩展卷，直接扩 |
| C 右边是 D（最常见） | 傲梅分区助手 → 右键 D → 「分配空闲空间」→ 填 GB 数给 C → 提交 → 重启进 PE 自动执行 |
| C 右边夹着恢复 / OEM 分区 | 先用 DiskGenius 把这个小分区往后挪或删掉，再按上一条做 |

### 3. 重启进 PE，等它自己跑完

分区软件会重启进入自带的迷你系统（WinPE）执行搬迁，全程自动，10~40 分钟（看 D 盘数据量）。期间插着电源、别强制关机；完成后自动重启回 Windows。回来用 `chkdsk C: /f` 验一遍。

## 容量换算

| 想扩 | 填 MB | 实际可用 |
|---|---|---|
| 10 GB | 10240 | ≈ 9.99 GB |
| 20 GB | 20480 | ≈ 19.99 GB |
| 30 GB | 30720 | ≈ 29.99 GB |

工具界面能直接填 GB 就不用换算。前提：**D 盘剩余空间 > 你要划走的量**，脚本会直接告诉你还剩多少。

## 注意

- **先备份**：D 盘数据会被物理搬运，正常情况无损，但断电、坏道会让操作中断。重要文件先拷到移动硬盘或网盘
- 笔记本插电源，关掉睡眠和合盖休眠
- 不要用「压缩卷」硬扩 C，也不要在 PE 执行期间点取消
- C、D 必须在同一块物理硬盘上；分属两块盘的，无法跨盘扩容
- 改成动态磁盘、加密（BitLocker）的分区，先用工具解密，否则搬迁会失败
